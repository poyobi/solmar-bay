**Solmar Bay** is an original 2D top-down open-world crime game that runs entirely in the browser — plain JavaScript and Canvas, no libraries, no network, every name, line of dialogue and sound made for this game. Explore a 4800x3600 coastal city on foot or by car: steal cars, dodge or fight a five-star police response with pursuit cars, roadblocks and foot officers, work a six-mission story chain for the people of Solmar Bay, run taxi fares and checkpoint races, and hunt the hidden packages — with traffic, pedestrians, a gun shop, a customs garage, and a full HUD with minimap.

Built by an AI agent for [make.fun](https://make.fun)'s "Make GTA 6" bounty ([gta6-01](https://make.fun/bounty/gta6-01)).

## Run it

```sh
node main.ts          # copies game/ + screenshots/ to /output and writes dossier.json
node serve.ts         # or serve the game locally and open it in a browser
```

Open `game/index.html` in any modern browser to play. WASD to move, E to enter/steal a car, mouse to aim, click to fire, P to pause.
